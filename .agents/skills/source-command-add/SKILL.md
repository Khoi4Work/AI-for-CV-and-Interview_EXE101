# source-command-add

Use this skill when the user asks to run the migrated source command `add`.

## Command Template

# Add Command
This command stages all current changes in the working directory.

## Execution
Run the following command:
`git add .`

## Post-condition
All modified and new files are staged and ready to be committed.
