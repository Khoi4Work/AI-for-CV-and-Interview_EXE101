# add

Use this skill when the user invokes `$add` or explicitly asks to stage repository changes.

## Command Template

# Add Command
This command stages all current changes in the working directory.

## Execution
Run the following command:
`git add .`

## Post-condition
All modified and new files are staged and ready to be committed.
